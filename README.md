# diff-test

## Summary

This is a test repository used by baz-scm for exercising diff and code review tooling. It contains small sample projects in multiple languages — Node.js (`node/`), Python (`python/`), TypeScript/NestJS (`typescript/nestjs/`), and a `binary/` example — intentionally including varied file types and code patterns to serve as fixtures for diff scenarios.

## Layout

- `python/` — assorted scripts
- `typescript/nestjs/` — sample NestJS app
- `node/` — small node example
